# 2026-08-01 底层性能优化复测

## 结论

本轮优化显著降低了默认加密路径的 CPU 与缓存外访问成本，但仍没有达到“可以停止底层优化、转入下一功能阶段”的门槛。

固定每连接 4 MiB 页缓存、100K 行、160 字节 Payload 和四读一写 WAL 压力后，加密路径相对首轮自身基线的三轮中位数变化如下：

| 指标 | 首轮基线 | 本轮 | 变化 |
|---|---:|---:|---:|
| 批量插入 | 278.134 ms | 249.414 ms | -10.3% |
| 随机点查 200K | 1718.046 ms | 1184.232 ms | -31.1% |
| 索引范围扫描 5K | 3121.655 ms | 2092.932 ms | -33.0% |
| 随机更新 100K | 2053.446 ms | 1521.301 ms | -25.9% |
| 压力读取吞吐 | 2,021,526 | 3,006,441 | +48.7% |
| 压力写入吞吐 | 143,968 | 151,552 | +5.3% |
| 读取 p50 | 13.460 µs | 9.284 µs | -31.0% |
| 读取 p95 | 44.327 µs | 31.327 µs | -29.3% |
| 读取 p99 | 115.763 µs | 78.687 µs | -32.0% |

三轮压力与 60 秒长压的错误数均为 0，结束后完整性检查通过。60 秒长压完成 16,257,117 次读取和 925,728 行更新，相对首轮 60 秒加密基线分别提升 29.2% 和 12.4%。

同一 4 MiB 约束下，本轮加密中位数仍只有同批系统 SQLite 压力读取吞吐的 38.2% 和写入吞吐的 73.8%；随机点查、范围扫描、更新耗时分别为系统 SQLite 的约 3.0、6.1、4.5 倍。这里不能用“开启加密必然更慢”掩盖差距，也不能声称性能已经过线。

## 已实现优化

1. C Statement 热路径取消外层连接互斥和 Statement 互斥叠加，以原子状态机保持调用顺序检查；prepare 时缓存参数数和结果列数。
2. 公共 C API 和普通 `Database` 继续默认 `FULLMUTEX`。连接池的读 Lease 与专用写线程已经提供单所有者约束，因此池内连接使用多线程内核的轻量模式。
3. 打包内核使用 `THREADSAFE=2` 并关闭全局 `MEMSTATUS` 计数，避免独立连接通过全局统计形成伪共享。
4. 新建加密库使用 AES-256-CBC 与 HMAC-SHA256 页认证；旧 HMAC-SHA512 库自动回退验证并保持原格式。认证没有关闭或截断。
5. OpenSSL 3 的不可变 HMAC Provider 描述只解析一次，每次页认证仍创建并立即释放独立的可变上下文，避免敏感状态在线程中延长驻留。
6. 连接池按 `memory_budget_bytes / (读连接数 + 1)` 限制每连接页缓存，并通过 `PoolStats::cache_bytes_per_connection` 暴露实际值。

## 缓存曲线

数据库主文件约 19.35 MiB。缓存从 4 MiB 增加到 8 MiB 和 16 MiB 后，默认加密路径的单连接阶段变化明显：

| 每连接缓存 | 点查 200K | 范围扫描 5K | 更新 100K | 压力读取 | 峰值 RSS |
|---:|---:|---:|---:|---:|---:|
| 4 MiB | 1184 ms | 2093 ms | 1521 ms | 3.01M | 58.9 MiB |
| 8 MiB | 964 ms | 967 ms | 1240 ms | 3.17M | 80.1 MiB |
| 16 MiB | 490 ms | 253 ms | 452 ms | 3.12M | 124.5 MiB |

8 MiB 和 16 MiB 是单轮缓存曲线，不与三轮中位数混为同一置信等级。16 MiB 已使范围扫描接近同缓存系统 SQLite，但四读并发吞吐没有按缓存等比例提升，说明剩余瓶颈还包括跨 C 边界逐列取值、页认证上下文创建以及加密内核本身的并发 CPU 成本。

## 性能门槛与下一切片

性能工作继续保持发布阻塞状态，下一切片不进入 AgentPlan 或新数据模型，优先完成：

- Rust 直接 API、`DatabasePool` 与 C ABI 的分层基准，区分包装成本、内核成本和调度收益；
- 有界批量 Row View，减少一次逻辑行跨越多次 FFI 边界，同时保留 SQLite 风格基础接口；
- 连接级认证上下文安全复用的可行性验证，要求连接关闭时清零和释放，不能使用跨连接线程本地密钥状态；
- ARM64 AES/SHA 硬件路径和 2/4/8/16 MiB 真机曲线；
- 长压中的 Checkpoint 干扰、冷缓存和总内存硬上限。
